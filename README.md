Made using Java and it find the highest scoring Scrabble word from user's input using a 100,000 word dictionary

Features:
-Duplicate letter limits apply
-Formats valid words in a clean table
-Calculates word values to output the highest score

What I learned:
-Working with arrays to store dictionary words
-Reading data from external files using Scanner
-Handling user input (q means quit)

Challenges:
-Handling duplicate and repeated letters
-Tracking highest score -> compare word scores by updating best word variable whenever higher scoring word found

To RUN:
Download the JAR file: WordUtils.jar
Type this command into terminal (make sure you are in the folder you downloaded the JAR file in):
java -jar WordUtils.jar
